# HiveMem

## A Hierarchical Long-Term Memory Engine for Autonomous AI Agents

HiveMem is an experimental memory architecture designed for autonomous agents.

It separates memory into:

- Working memory
- Episodic memory
- Semantic memory

The system will also support:

- Memory consolidation
- Provenance tracking
- Importance scoring
- Confidence tracking
- Forgetting and archival policies
- Benchmarking long-term recall
